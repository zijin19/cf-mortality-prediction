# Synthetic data dictionary

The files in `data/raw/` are generated by `R/00_simulate_data.R`. They contain
no real CCFR observations.

## `patient.csv`: one row per synthetic patient

| Variable | Type | Description |
|---|---|---|
| `patient_id` | integer | Synthetic identifier |
| `age_in_2011` | numeric | Age at the beginning of the study window |
| `birth_year` | integer | Calendar year derived from synthetic age |
| `sex` | factor | Female or male |
| `age_at_diagnosis` | numeric | Age at CF diagnosis |
| `df508` | factor | Homozygous, heterozygous, or other |
| `pancreatic_insufficiency` | binary | Pancreatic insufficiency indicator |
| `event_indicator` | binary | Death or lung transplant during follow-up |
| `event_type` | factor | Death, lung transplant, or censored |
| `event_age` | numeric | Age at the composite event, if observed |
| `followup_age` | numeric | Age at event or administrative censoring |

## `annual_encounter.csv`: one row per synthetic patient-year

| Variable | Type | Description |
|---|---|---|
| `patient_id` | integer | Links to `patient.csv` |
| `report_year` | integer | Calendar year of measurement |
| `current_age` | numeric | Age at measurement |
| `fev1_pct_predicted` | numeric | FEV1 percent predicted |
| `fvc_pct_predicted` | numeric | FVC percent predicted |
| `bmi_percentile` | numeric | BMI-for-age percentile |
| `cfrd` | binary | CF-related diabetes |
| `iv_antibiotic_times` | integer | Courses during the year; 3+ grouped later |
| `home_oxygen` | binary | Home oxygen use |
| `b_cepacia` | binary | B. cepacia infection |
| `p_aeruginosa` | binary | P. aeruginosa infection |
| `s_aureus` | binary | S. aureus infection |
| `corticosteroids` | binary | Oral corticosteroid use |
| `depression` | binary | Recorded depression |

The generator adds modest missingness to FEV1, FVC, and BMI. The preparation
script removes incomplete measurement-years, following the complete-record rule
used for these three variables in the thesis. The synthetic missingness rate and
joint predictor relationships are illustrative, not estimates of the CCFR data.
